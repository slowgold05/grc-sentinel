Status: **reviewed source foundation — voluntary assurance objective only**

NIST describes the framework as voluntary, rights-preserving, non-sector-specific, and
use-case-agnostic. Its Core uses four functions: `GOVERN`, `MAP`, `MEASURE`, and `MANAGE`.
The Playbook contains optional suggestions rather than a universal checklist.

Implementation may store the published function/category/subcategory identifiers, source version,
and selected outcomes. It must not convert Playbook suggestions into mandatory law, claim NIST
certification, or invent crosswalks. NIST states that AI RMF 1.0 is under revision, so any import
must remain pinned to NIST AI 100-1 and use framework drift for a successor version.

Acceptance case: selecting NIST AI RMF records a voluntary assurance objective and source version;
it never creates a legal determination.
