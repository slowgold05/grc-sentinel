# NIST AI 600-1 source review

Status: **reviewed source foundation — voluntary Generative AI profile only**

| Field | Value |
| --- | --- |
| Publisher | US National Institute of Standards and Technology |
| Identifier | NIST AI 600-1 |
| Publication | July 2024; editorial approval 25 July 2024 |
| Primary source | <https://doi.org/10.6028/NIST.AI.600-1> |
| Relationship | Cross-sectoral profile and companion to NIST AI RMF 1.0 |
| Repository review date | 2026-09-11 |

The profile identifies risks that are unique to or intensified by Generative AI and supplies
suggested actions aligned to AI RMF functions and subcategories. Its stated primary considerations
are governance, content provenance, pre-deployment testing, and incident disclosure.

Implementation may preserve the publication identifier, section/risk names, linked AI RMF
subcategories, and source text permitted by NIST. `Confabulation` is the initial acceptance risk
because GRC Sentinel already rejects unsupported citations. The profile does not set universal
test thresholds, establish legal applicability, or certify an AI system; reviewers must select
actions and thresholds for the use case.
